# 完整图纸库

正式 APK 和 Windows 安装程序内置 1265 张授权高清图纸及对应预览，安装后可以离线浏览，不依赖图库服务器。

![图纸库真实界面](https://xuange6610.github.io/PindouAI/screenshots/collection-android.jpg)

## 浏览和搜索

入口：`底部导航 → 图纸库`。

1. 先按 24 个顶层分类缩小范围。
2. 使用原文件名搜索关键词。
3. 在预览卡片中查看缩略图和基本信息。
4. 需要精细检查时选择读取高清原图。
5. 通过收藏、识别、编辑或保存继续使用图纸。

图库内容按动漫人物、卡通、动物、古风、美食、传统文化、游戏角色和其他主题组织。分类是筛选入口，不代表图纸只能用于某一种作品。

## 从图纸继续制作

打开一张图纸后可以：

- 直接作为作品保存。
- 进入图片色号识别，查看每个网格的颜色编号。
- 送入照片转图纸流程，换用不同尺寸或色库。
- 收藏到自定义分组。
- 进入画板做局部修改。

高清原图和预览图都随正式包提供；如果只有预览而无法读取原图，先确认安装的是 Release Assets 中的完整包，而不是源码运行或轻量测试包。
