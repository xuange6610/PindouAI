## Windows 校验

```powershell
Get-FileHash .\PindouAI-Android-v2.8.10.apk -Algorithm SHA256
Get-FileHash .\PindouAI-Windows-v2.8.10-x64-Setup.exe -Algorithm SHA256
```

## Linux/macOS 校验

```bash
sha256sum PindouAI-Android-v2.8.10.apk
sha256sum PindouAI-Windows-v2.8.10-x64-Setup.exe
```

输出应与 Release 和 `SHA256SUMS.txt` 完全一致。不同则删除文件并从官方 Release 重新下载。
