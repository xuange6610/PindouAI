# Windows 版完整使用

Windows 版与 Android 版共享 Flutter 应用能力，适合大屏画板、批量整理、颜色核对和打印前检查。

## 安装

从 [最新 Release](https://github.com/xuange6610/PindouAI/releases/latest) 下载 `PindouAI-Windows-v2.8.10-x64-Setup.exe`。这是包含完整图库的单文件安装程序，不需要再下载图纸包。

1. 下载完成后核对文件大小和 SHA-256。
2. 双击安装程序，按向导完成安装。
3. 从开始菜单启动“拼豆 AI 设计”。
4. 首次进入图纸库时，应用从安装目录读取内置原图。

## 桌面布局

Windows 使用更宽的导航和内容区域，同样包含首页、处理中心、作品、收藏、自定义画板、图纸库、AI 对话、色库和“我的”。鼠标滚轮用于浏览，画板支持鼠标点击、拖动和快捷工具操作。

![Windows 自定义画板](https://xuange6610.github.io/PindouAI/screenshots/custom-board-windows.png)

## 适合 Windows 的工作流

- 在大屏上核对编号格子和颜色统计。
- 使用自定义画板进行逐格修正和批量换色。
- 批量整理、重命名和导出作品。
- 导出 PDF 后在打印软件中检查分页与缩放。
- 使用 `.beadboard` 和 `.beaddevice` 在设备间迁移。

## 图库资源

完整图纸安装到程序目录的 `artwork` 资源目录，以避免原始中文素材目录导致 Windows 长路径问题。不要手动移动或删除该目录，否则图纸库可能只能显示预览或无法读取原图。

## 卸载与重装

重装、换盘或卸载前先从应用内完成换机备份。安装程序文件和程序目录不是个人作品备份；不要假设卸载后数据一定保留。
