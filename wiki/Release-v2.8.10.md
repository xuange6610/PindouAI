# v2.8.10 发布说明

## 版本信息

- 应用版本：`2.8.10+28`
- Git 标签：`v2.8.10`
- 目标分支：`main`

## Release Assets 上传格式

请在 GitHub Release 的 Assets 区上传：

```text
PindouAI-Android-v2.8.10.apk
PindouAI-Windows-v2.8.10-x64-Setup.exe
SHA256SUMS.txt
```

Release 正文模板见仓库的 [`docs/GITHUB_RELEASE_v2.8.10.md`](https://github.com/xuange6610/PindouAI/blob/main/docs/GITHUB_RELEASE_v2.8.10.md)。文件大小和 SHA-256 必须在上传完成后使用真实值填写。

## 完整功能

照片转图纸、处理中心、结果页、作品/收藏/回收站、自定义画板、文字拼豆、图片色号识别、手动抠图、1265 张图纸库、多品牌色库、AI 对话、AI 制图、AI 任务中心、API 管理、AI 用量、换机备份、主题/语言/音效和导出均包含在本版本说明范围内。

## 验收重点

- Android 安装后首页和底部导航可打开。
- 无网络时完成一次照片转图纸并导出 PNG/PDF。
- 图纸库能浏览完整分类并读取高清原图。
- Windows 安装后能打开作品、画板、色库和导出页面。
- 校验文件中的哈希与实际附件一致。
