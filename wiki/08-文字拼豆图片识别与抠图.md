# 文字拼豆、图片识别与抠图

这三个工具处理“没有照片”或“已有图纸需要继续加工”的场景。

## 文字拼豆

入口：`首页 → 文字拼豆`。

输入中文、英文、名字或短句后，可以调整字体、字号、字距、方向、画板大小、颜色和背景。生成后保存到“我的作品”，或送到自定义画板逐格修正。

![文字拼豆结果截图](https://xuange6610.github.io/PindouAI/screenshots/text-bead.png)

文字较长时先增加画板宽度或选择四宫格布局；制作姓名牌和短句时优先确认字体笔画在目标格数下仍然清楚。

## 图片色号识别

入口：`首页 → 图片色号识别`。

1. 选择现成图纸或参考图片。
2. 指定品牌色库和网格大小。
3. 查看原图、拼豆预览、坐标位置和每格色号。
4. 点击格子查看该点颜色信息。

它适合核对外部图纸、整理采购清单或把图库内容转成可编辑方案。AI 预处理是可选项，没有 API 时仍可使用本地识别。

## 手动抠图

从编辑页进入手动抠图，使用保留、擦除和恢复操作处理主体与背景，再将透明结果送入照片转图纸流程。人物、商品、宠物和需要干净轮廓的素材适合先抠图。

AI 抠图需要配置兼容图片 API；本地手动抠图不需要网络。抠图完成后要检查头发、手指和细线区域，必要时回到画板修正。
