# 结果页与导出

结果页用于检查图纸是否真的能制作，而不只是展示像素效果。生成后应依次核对轮廓、编号、颜色数量和总豆数。

![结果与参数真实截图](https://xuange6610.github.io/PindouAI/screenshots/result-android.png)

## 四种检查视图

1. **真实色预览**：用方形像素检查构图和整体配色。
2. **圆形拼豆效果**：模拟豆粒外观，观察成品的视觉密度。
3. **编号格子图**：每格显示当前品牌色号，是照图摆豆的主要视图。
4. **颜色统计**：按色号统计数量，用于分装、备料和采购。

颜色统计总数应与画板格子数量和透明格处理规则一致。发现某个颜色过多或轮廓不清时，可以返回参数页减少颜色、调整尺寸或启用去噪。

## 结果页操作

- 保存、重命名或收藏作品。
- 返回参数页面并生成不同方案。
- 转入自定义画板逐格修正。
- 在配置 AI 后尝试修复模糊画面，再沿用参数生成新版本。
- 删除作品后进入回收站，而不是立即永久消失。

## 导出类型

| 导出内容 | 适用场景 |
| --- | --- |
| 真实色 PNG | 分享、预览和方案确认 |
| 圆形效果图 | 模拟成品观感 |
| 编号格子图 | 手机查看或照图摆豆 |
| 颜色统计/购买清单 | 备料、分装和采购 |
| 分页 PDF | 打印大图纸和离线制作 |

自定义画板还支持 `.beadboard` 工程文件。工程文件保留可编辑格子数据，PNG/PDF 只用于查看和交付，两者不能互相替代。

## 导出建议

1. 大画板优先导出 PDF，打印前查看分页和缩放。
2. 分享给他人时同时提供编号图和颜色清单，并注明使用的品牌色库。
3. Android 保存失败时检查系统相册/文件权限和剩余空间。
4. 实体豆会受批次、显示器和环境光影响，正式采购前用实物色卡复核。
