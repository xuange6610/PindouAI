# 多品牌色库与颜色匹配

色库决定结果页显示的编号和采购清单。PindouAI 提供多品牌、多个系列的本地颜色数据，可在生成参数和色库页面选择。

## 色库页面

入口：`底部导航 → 色库`。

- 按品牌和系列筛选。
- 搜索色号或颜色名称。
- 查看 RGB、HEX、LAB 和近似信息。
- 生成色卡图片或分享颜色资料。

项目中包含 Artkal、MARD、COCO、Perler、Hama 等兼容方案。不同品牌的编号不能直接混用；换品牌后请重新生成或重新核对每个格子的编号。

## 匹配流程

照片转换不是简单地取最近 RGB 值，处理流程大致为：

`方向校正 → 方形裁切 → 目标格数缩放 → LAB 聚类降色 → CIEDE2000 最近色匹配 → 品牌色号图纸`。

LAB 用于更接近人眼的颜色空间，CIEDE2000 用于比较候选色差。算法得到的是工程匹配结果，实体豆仍会受到批次、光线和显示器影响。

## 采购前核对

1. 先确定制作时使用的实际品牌和系列。
2. 在结果页记录色号和数量。
3. 用实体色卡复核相近色，尤其是肤色、灰色和深色。
4. 不要仅凭屏幕截图判断两种实体豆完全一致。
