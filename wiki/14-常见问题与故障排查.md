# 常见问题与故障排查

## APK 无法安装

- 确认 APK 已完整下载，文件名与 Release 一致。
- 只为当前浏览器或文件管理器开启“允许安装未知应用”。
- 旧包签名不同时，先备份作品，再卸载旧包。
- 使用 `SHA256SUMS.txt` 检查文件是否损坏。

## Windows 安装器被拦截

当前安装器没有商店签名时，SmartScreen 可能提示未知发布者。先确认下载来源是项目 Release，核对 SHA-256，再决定是否运行；不要从第三方网盘下载改名版本。

## 图纸库不完整

确认安装的是完整 APK 或带 `x64-Setup` 的 Windows 包。源码运行还必须安装 Git LFS 并完整拉取大文件。Windows 不要删除安装目录中的 `artwork`。

## 没有网络能否使用

可以。照片转图纸、画板、图纸库、作品、收藏、色库和 PNG/PDF 导出都可离线使用。AI 对话、AI 制图、AI 修复和兼容 API 检测需要网络。

## AI 没有结果

先在 API 设置运行单项检测，检查地址、协议、密钥、模型、余额和错误码。图片模型通常比对话模型慢，使用任务中心查看状态，不要重复提交。

## 导出失败

检查文件/相册权限、可用空间和目标目录。大画板 PDF 需要更多内存与临时空间；先降低画板尺寸验证。导出工程请使用 `.beadboard`，不要把 PNG 当作可编辑备份。

## 色号与实体豆有色差

屏幕、灯光和实体批次都会产生差异。内置 RGB/LAB 是工程匹配数据，不是对每一批实体豆的实验室保证；采购前使用实物色卡复核。

## 作品误删或换机丢失

先检查作品回收站和画板临时回收站。恢复出厂设置、卸载或系统清理前必须主动导出换机备份；API 密钥不会包含在备份中。

## 提交问题

在 [GitHub Issues](https://github.com/xuange6610/PindouAI/issues) 提供版本、平台、复现步骤、实际提示和必要截图。不要公开 API 密钥、私人照片、签名文件或本机路径中的个人信息。
