# 版权、安全与参与贡献

## 许可证边界

- PindouAI 原创源代码采用 [Apache License 2.0](https://github.com/xuange6610/PindouAI/blob/main/LICENSE)。
- 1265 张高清图纸和对应预览适用单独的 [`ARTWORK_LICENSE.md`](https://github.com/xuange6610/PindouAI/blob/main/ARTWORK_LICENSE.md)。
- 图纸不因存放在开源仓库或安装包中而自动变成 Apache-2.0 素材。
- 品牌名称仅用于色号兼容说明，商标属于各自权利人。

再发布源码时应保留 LICENSE、NOTICE 和原始署名。不得把图纸单独打包转售、去除权利说明，或声称第三方品牌官方认可本项目。

## 用户数据安全

- 不要把 API 密钥、`.env`、数据库密码、签名 keystore、私钥或真实个人照片提交到 GitHub。
- AI 请求会发送到用户填写的第三方地址，使用前阅读对应服务条款。
- 换机备份可能包含私人作品，应通过可信渠道传输和保存。
- 发布日志和 Issue 截图要遮盖密钥、令牌、个人路径和私人素材。

## 参与贡献

1. Fork 仓库并从 `main` 创建功能分支。
2. 只修改与问题相关的文件，保留现有功能和授权说明。
3. Flutter 源码变更至少运行 `flutter analyze` 和相关 `flutter test`。
4. UI 变更要验证 Android/Windows 布局、键盘操作和真实截图。
5. 提交 Pull Request，说明行为变化、测试证据和剩余风险。

完整要求见 [`CONTRIBUTING.md`](https://github.com/xuange6610/PindouAI/blob/main/CONTRIBUTING.md)。
