# 导出、备份、隐私与版权

## 结果导出

结果页提供：

- 真实色预览 PNG。
- 圆形拼豆效果图。
- 带色号编号的格子图。
- 颜色统计和购买清单。
- 分页 PDF 图纸。

自定义画板还可以导出完整 `.beadboard` 工程，方便在另一台设备继续编辑。

![设置与隐私真实截图](https://xuange6610.github.io/PindouAI/screenshots/settings-windows.png)

## 换机备份

进入 `我的 → 换机备份`，可选择作品、收藏、画板、回收站、处理历史、图纸库设置和本地音乐。新设备选择备份文件即可恢复；API 密钥受系统安全存储保护，需要重新填写。

## 隐私

- 照片转图纸默认只在本机处理。
- 本地作品和导出文件由用户自己保存和管理。
- 只有主动配置并调用 AI/云服务时，相关图片或文字才会离开设备。
- 不要把 API 密钥、签名 keystore、数据库密码或 `.env` 文件提交到 Git。

## 许可证边界

原创源代码采用 Apache-2.0。随应用分发的图纸和预览遵循仓库根目录 [`ARTWORK_LICENSE.md`](https://github.com/xuange6610/PindouAI/blob/main/ARTWORK_LICENSE.md)，不因源代码开源而自动获得 Apache-2.0 授权。
