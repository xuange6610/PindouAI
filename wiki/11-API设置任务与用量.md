# API 设置、任务与用量

PindouAI 不内置公共 AI 密钥。对话、图片和视频能力需要用户自行填写合法的官方或兼容中转 API。

## API 设置入口

从 `我的 → API 设置`，或 AI 页面右上角设置按钮进入。

可配置内容包括：

- API 地址和协议类型。
- 密钥或授权信息。
- 对话、图片、视频三个模型。
- 多套配置的保存、切换和管理。
- 从剪贴板导入或导出完整配置。

## 连接检测

保存前后可以分别测试对话、图片和视频，也可以一键检测全部模型。检测结果只说明当时接口可访问，不保证模型一直在线、余额充足或支持所有附件格式。

常见错误：

| 提示 | 优先检查 |
| --- | --- |
| 401/403 | 密钥、权限和服务地址 |
| 404 | 接口路径、协议和模型名称 |
| 429 | 余额、速率限制和并发任务 |
| 超时 | 网络、模型耗时和中转稳定性 |
| 返回格式错误 | 服务是否真正兼容所选协议 |

## AI 任务中心

AI 制图可以进入后台任务中心。每个任务包含排队、执行、失败、成功和取消状态；可查看输入、模型、结果、错误和重试记录。离开页面不会把本地照片转换成云任务，只有用户主动调用 AI 时才发送请求。

## AI 用量

从 AI 对话菜单进入用量页面，可以查看今天、本周、本月和本年的 Token，近 7 天趋势、24 小时分布、用途拆分和模型排行。应用统计用于本地了解调用情况；最终账单仍以 API 服务商记录为准。

## 密钥安全

API 密钥保存在系统安全存储，不写入安装包和换机备份。不要把配置截图、日志、`.env` 或密钥粘贴到 GitHub Issue。换机后需要在新设备重新填写。
