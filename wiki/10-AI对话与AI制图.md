# AI 对话与 AI 制图

AI 是可选扩展。未配置 API 时，照片转图纸、完整图库、自定义画板、作品管理、色库和导出仍可离线使用。

## AI 对话

入口：`底部导航 → AI 对话`。

- 新建、切换和删除聊天。
- 发送文字、图片和支持的附件。
- 根据当前 API 配置切换对话模型。
- 查看历史，为聊天添加备注。
- 分享当前界面截图或完整 Markdown 聊天记录。
- 查看请求状态、错误和停止生成。

发送图片或附件前要确认第三方 API 的隐私条款。不要把身份证、私人照片、密钥文件或未授权资料发送给外部模型。

## AI 制图

入口：`首页 → AI 制图`。

1. 选择预设拼豆风格或目标效果。
2. 上传参考图片，填写补充要求。
3. 选择在当前页面等待，或放入任务中心后台处理。
4. 生成后查看历史和任务详情。
5. 对满意的图片选择“转拼豆图”，再进入本地色号映射流程。

AI 生成的是参考图片，不会自动成为可制作图纸。必须继续设置画板大小、颜色数量和品牌色库，生成编号格子与用量清单。

## AI 修复与预处理

图片色号识别和结果页可以调用图片模型改善模糊参考图、补足细节或保留主体。模型输出可能改变颜色、文字和构图，处理后要与原图对照，不能把 AI 结果当作无误的原始资料。

## 历史和重试

AI 制图历史保存生成状态和结果。任务失败时先查看错误，不要立即连续重复提交；确认地址、模型、余额和网络后再重试。后台任务支持查看详情和失败自动重试设置。
