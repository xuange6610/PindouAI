# 自定义画板

自定义画板适合从空白开始创作、修正照片转换结果、制作文字标识和进行局部换色。

![Windows 自定义画板真实截图](https://xuange6610.github.io/PindouAI/screenshots/custom-board-windows.png)

## 新建画板

入口：`底部导航 → 自定义画板`。

1. 设置宽度、高度和当前色库。
2. 选择背景和透明格规则。
3. 创建画板后逐格绘制。

画板尺寸支持 5 到 200 格；大画板更适合 Windows 宽屏编辑，Android 可以缩放查看。

## 工具

| 工具 | 用法 |
| --- | --- |
| 画笔 | 点击或拖动填入当前颜色 |
| 橡皮 | 清除指定格子 |
| 填充 | 填满连续区域 |
| 取色 | 从已有格子读取颜色 |
| 移动 | 平移画布或调整视图 |
| 撤销/重做 | 回退和恢复最近操作 |
| 批量换色 | 把一种颜色替换为另一色号 |

## 草稿和工程文件

应用会保存自动草稿，异常退出后可恢复最近版本。通过 `.beadboard` 导入/导出完整可编辑工程，换机或交给其他设备继续编辑；PNG 和 PDF 不包含可编辑的格子数据。

## 从结果页继续编辑

结果页选择“应用画板”后，会带入当前网格和色号。建议先复制或另存为，再进行大范围修改，避免覆盖原始照片方案。
