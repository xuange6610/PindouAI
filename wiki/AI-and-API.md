# AI 与 API

## AI 对话

入口：`底部导航 → AI 对话`。支持新建聊天、切换对话模型、发送文字和图片附件、查看历史、给聊天添加备注，以及分享当前界面截图或完整 Markdown 记录。

## AI 制图

入口：首页的 AI 制图。选择风格、上传参考图、输入补充要求后，可以在当前页等待，也可以放入任务中心继续使用其他功能。支持失败自动重试、历史记录、任务详情和“转拼豆图”。

## AI 色号识别与 AI 修复

图片色号识别可以先调用图片模型改善模糊参考图，再进行本地色号映射；结果页的 AI 修复会尽量保持原构图和颜色关系，再沿用原参数生成新作品。

## API 设置

入口：`我的 → API 设置`，或 AI 页面右上角设置按钮。

- 填写 API 中转地址和协议。
- 保存对话、图片、视频三个模型。
- 剪贴板一键导入/导出完整配置。
- 单独测试对话、图片、视频，或一键检测全部模型。
- 查看连接结果和供应商余额（如果接口支持）。
- API 密钥保存在系统安全存储，不写入安装包和换机备份。

## AI 用量

从 AI 对话菜单进入 AI 用量，可查看今天、本周、本月、本年 Token，近 7 天趋势、24 小时分布、用途拆分和模型排行。

AI 是可选扩展。没有 API 配置时，照片转图纸、图纸库、画板、作品和导出仍可离线使用。
