# 设置、备份、声音与隐私

“我的”页面集中管理外观、语言、声音、API、数据迁移、软件说明和隐私选项。

![Windows 设置真实截图](https://xuange6610.github.io/PindouAI/screenshots/settings-windows.png)

## 外观和语言

- 切换亮色、暗色或跟随系统主题。
- 选择强调色和界面语言。
- 调整按钮文字、动画或适合当前设备的显示选项。

更改主题不会影响作品色号；结果页的真实色预览仍基于作品数据。

## 点击音效与本地音乐

可以开启或关闭按钮音效，管理本地音乐播放。外部音乐平台链接受平台登录、版权和 DRM 限制，软件不会绕过授权；使用用户有权访问的本地文件或公开直链。

## 一键换机

入口：`我的 → 换机备份`。

备份可选择作品、收藏、画板、回收站、处理历史、图纸库设置、本地音乐和软件设置。导出的 `.beaddevice` 文件可能包含私人作品，应妥善保管。

恢复步骤：

1. 在旧设备选择需要迁移的内容并导出备份。
2. 把备份文件完整传到新设备。
3. 新设备安装相同或更新版本的 PindouAI。
4. 进入换机恢复并选择文件，核对恢复结果。
5. API 密钥不会进入备份，需要重新填写。

## 隐私边界

- 照片转图纸、图库、画板、作品和导出默认在本机运行。
- 只有主动配置并调用 AI/云服务时，相关文字或图片才会发送到所填地址。
- 本地作品和导出文件由用户自己保存和管理。
- 恢复出厂设置或清空应用数据前必须先备份；这类操作可能不可逆。
