# 首页与照片制图

首页是创建入口和最近作品入口。照片制图的主流程是：`首页 → 选择素材 → 裁切 → 参数 → 处理中心 → 结果页`。

![首页真实截图](https://xuange6610.github.io/PindouAI/screenshots/home-android.png)

## 首页区域

- **从相册选择**：导入一张已有照片，是最常用入口。
- **相机**：调用系统相机拍摄后继续处理；应用不会在后台自行拍照。
- **批量导入**：一次选择多张素材，分别进入待处理流程。
- **文字拼豆**：不依赖照片，把文字渲染为像素图。
- **图片色号识别**：对现有拼豆图或参考图显示网格和色号。
- **AI 制图**：需要自行配置兼容图片 API，是可选入口。
- **最近作品**：继续查看、编辑或导出最近保存的图纸。

## 选择适合的照片

清晰、主体完整、背景简洁的照片最容易得到可制作的结果。强压缩、小尺寸、逆光或背景过于复杂的图片可能产生大量零碎色点。人物照片建议让脸部占画面较大比例；商品或角色图可以先抠图再转换。

## 裁切和构图

1. 导入后先检查图片方向。
2. 拖动照片改变主体位置，双指或鼠标缩放。
3. 把重要轮廓放在生成范围内，不要让眼睛、文字或边缘被裁掉。
4. 确认后进入参数页面。裁切只决定送入转换的区域，不会覆盖手机中的原图。

## 批量导入

批量入口适合订单图、同一系列素材或需要比较多种照片的场景。每张图片仍有独立任务和结果；处理中心可以查看排队、失败、取消和成功状态。不要在任务处理中删除原始文件或清理应用数据。

## 最近作品

点击最近作品可直接打开结果页。作品已经保存时，可以再次调整参数生成新方案，也可以转入自定义画板逐格修改。重新生成前先确认是否要保留旧版本；重要方案建议重命名或导出。

## Android 与 Windows 差异

两端的数据能力一致。Android 以底部导航和触控为主，适合拍照、快速生成与随身查看；Windows 利用宽屏显示更多面板，适合大画布、批量整理和打印前核对。
