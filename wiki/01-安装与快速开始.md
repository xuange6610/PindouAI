# 安装与快速开始

本页适合第一次使用 PindouAI。Android 与 Windows 的正式包都包含完整 1265 张授权图纸，核心功能安装后可离线运行。

## 1. 选择下载文件

打开 [最新 Release](https://github.com/xuange6610/PindouAI/releases/latest)：

| 平台 | 文件 | 用途 |
| --- | --- | --- |
| Android | `PindouAI-Android-v2.8.10.apk` | 手机和平板完整安装包 |
| Windows x64 | `PindouAI-Windows-v2.8.10-x64-Setup.exe` | 电脑完整安装程序 |
| 校验 | `SHA256SUMS.txt` | 检查文件是否完整 |

不要下载 GitHub 自动生成的 `Source code (zip)` 当作安装包；它只用于开发和审阅源码。

## 2. Android 安装

1. 等待 APK 完整下载到手机“下载”目录。
2. 点击 APK。Android 首次从浏览器安装时，会要求为当前浏览器或文件管理器开启“允许安装未知应用”。
3. 返回安装页，确认应用名为“拼豆 AI 设计”，然后完成安装。
4. 如果手机上已有签名不同的旧包，系统可能拒绝覆盖；先备份作品，再卸载旧包并重新安装。
5. 首次打开后，相册、相机和通知权限都只在相关操作需要时申请。

![Android 首页真实截图](https://xuange6610.github.io/PindouAI/screenshots/home-android.png)

## 3. Windows 安装

1. 下载带 `x64-Setup.exe` 的完整安装程序。
2. 双击运行并按向导安装。Windows SmartScreen 如果提示未知发布者，应先核对文件名和 SHA-256，再选择是否继续。
3. 从开始菜单启动“拼豆 AI 设计”。安装程序会把完整图库放到程序资源目录，首次启动不需要另行下载图纸。
4. 卸载应用不会替你备份个人作品；换电脑前先使用“我的 → 换机备份”。

## 4. 完成第一张图纸

1. 首页点击“从相册选择”，挑一张主体清楚、光线均匀的照片。
2. 移动和缩放照片，确定要保留的正方形区域。
3. 选择画板大小、色库和颜色数量。第一次可从较小画板和较少颜色开始。
4. 点击生成，在处理中心等待完成。
5. 进入结果页，检查真实色、圆形效果、编号格子和颜色用量。
6. 保存到“我的作品”，再导出 PNG 或 PDF。

## 5. 第一次使用建议

- 核心制图不需要注册账号，也不需要配置 API。
- AI 页面没有配置时可以跳过，不影响照片、图库、画板、作品和导出。
- 先做一张小图验证屏幕显示、色号和实体豆色卡，再处理大幅作品。
- 重要作品及时导出或换机备份，不要只依赖手机应用数据。
