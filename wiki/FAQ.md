# 常见问题

## APK 安装失败怎么办？

确认下载已经完成，删除损坏文件后重新下载；Android 设置中只为当前浏览器开启“允许安装未知应用”。如果设备已有旧包且签名不同，需要先卸载旧包再安装体验版。

## 没有网络能不能用？

照片转图纸、画板、图纸库、作品、收藏、色库和 PNG/PDF 导出都可以离线使用。AI 对话、AI 制图、AI 色号识别和在线原图库需要网络与相应配置。

## 为什么看不到完整图纸？

确认安装的是 Release Assets 中的完整 APK，而不是轻量测试包；Windows 也要使用带 `x64-Setup` 的完整安装程序。源码运行时还需要正确拉取 Git LFS 文件。

## AI 为什么没有结果？

检查 API 地址、协议、密钥和对应模型是否填写正确，先运行“测试 AI 连接”。图片/视频模型可能较慢，可以把任务放到任务中心并开启自动重试。

## API 密钥会进入备份吗？

不会。密钥保存在系统安全存储；换机后需要在新设备重新填写。

## 色号和实体豆完全一致吗？

内置 RGB/LAB 用于工程匹配和流程验证，实体豆会受批次、光线和显示器影响。采购前请用实际色卡复核。

## 如何反馈问题？

请在 [GitHub Issues](https://github.com/xuange6610/PindouAI/issues) 附上版本号、平台、复现步骤和必要的日志截图；不要上传 API 密钥或私人照片。
