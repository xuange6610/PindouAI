# 《拼豆 AI 设计》商业 PRD

版本：1.0 MVP
产品负责人 / 版权所有人：xuan
平台：Android（本次交付）、iOS（代码兼容，待签名发布）

## 1. 产品目标

把任意照片转换为可实际制作的 2.6mm 拼豆图纸。用户在一个闭环中完成图片导入、尺寸和色数选择、MARD 221 色近似匹配、效果预览、编号格子图、用量统计、购买清单和 PDF 导出。

核心价值不是普通像素滤镜，而是“图片颜色 → CIE LAB → Delta E → 品牌色号 → 可采购数量”的制作链路。

## 2. 用户与场景

- DIY 初学者：快速把宠物、头像、卡通图变成图纸。
- 拼豆爱好者：控制板型尺寸和色数，查看逐格色号。
- 工作室与手工商家：生成材料清单和打印版图纸。
- 已有库存用户：后续可扫描库存色并限制可用色生成。

## 3. MVP 功能范围

1. 首页：相册导入、相机拍摄、最近作品、热门创作方向。
2. 编辑：正方形中心裁切、20/50/100/200 板型、8–96 色、肤色保护、孤点去噪。
3. 转换：图像方向校正、下采样、LAB 聚类、CIEDE2000 最近色、MARD 221 色号映射。
4. 结果：真实色预览、编号格子图、颜色统计、购买清单。
5. 导出：PNG 效果图、分页 PDF 图纸，通过系统分享面板保存或发送。
6. 作品：本地持久化、再次查看、删除。
7. 色库：按系列浏览、色号检索、RGB/HEX/LAB 信息。
8. 我的：产品信息、算法说明、版权信息与数据声明。

## 4. 验收指标

- 221 个标准系列色号唯一、可检索，并包含结构化品牌/系列/编号/RGB/HEX/LAB/尺寸/类型字段。
- 任意可解码 JPG/PNG/HEIC（由系统选择器支持）可生成 20–200 方格作品。
- 每个输出格必定映射到一个色号，统计数量之和等于宽×高。
- 相同输入与配置产生确定性结果。
- 断网时仍可完成导入、生成、保存和导出。
- Android Release APK 可安装；静态分析和自动测试通过。

## 5. 商业边界与风险

- 当前需求没有提供 MARD 官方完整色卡的经校准 RGB/LAB 原始数据。因此 MVP 内置的是完整 221 色号结构与工程预置近似色，只适合屏幕设计和流程验证，不宣称等同于实体豆在特定光源下的测色值。
- 上线采购前应使用实体色卡在 D65/2° 条件下测量 LAB，记录批次、光源、测量设备和版本，再通过后台导入替换预置值。
- 人像优化在 MVP 中使用可解释的肤色区域启发式保护；生产版建议接入端侧人脸/语义分割模型并建立真人样本回归集。
- 品牌名称仅用于色号兼容说明；发布前需要完成商标、色卡数据授权和隐私合规复核。

## 6. 后续路线

- V1.1：库存色盒识别、仅用已有色生成、手工逐格编辑、撤销/重做。
- V1.2：Perler/Artkal 等独立色库、云同步、账号与会员。
- V1.3：端侧人像分割、背景移除、模板市场和商家采购链接。
