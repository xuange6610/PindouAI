## 这个版本包含什么

- 首页：相册、相机、批量导入、文字拼豆、图片色号识别、AI 制图和最近作品。
- 照片转图纸：方向校正、裁切、20–200 格画板、颜色数量、肤色保护、去噪、抠图和模板。
- 结果页：真实色预览、圆形拼豆效果、编号格子图、颜色统计、购买清单、PNG/PDF 导出。
- 我的作品：搜索、排序、重命名、拖动重排、收藏、批量导入导出、批量保存、回收站和再次生成。
- 收藏：自定义收藏分组和批量管理。
- 自定义画板：画笔、橡皮、填充、取色、移动、撤销/重做、自动草稿、临时回收站、批量换色、`.beadboard` 工程导入导出。
- 图纸库：1265 张授权图纸、24 个顶层分类、文件名搜索、预览/高清原图切换、收藏和管理。
- 色库：MARD、Artkal、COCO、Perler、Hama 等色号搜索与 RGB/HEX/LAB 信息查看。
- AI 对话：文字和图片附件、多模型切换、历史、备注、截图分享和 Markdown 导出。
- AI 制图：风格选择、照片上传、补充要求、后台任务、自动重试、历史和结果转拼豆。
- API 设置：服务地址、协议、密钥、对话/图片/视频模型，剪贴板配置导入导出和连接测试。
- AI 用量：按日/周/月/年查看 Token，查看近 7 天和 24 小时趋势及模型拆分。
- 我的：语言、主题、强调色、点击音效、本地音乐、软件公告、内置浏览器、换机备份/恢复和版权说明。

## Android 安装

1. 下载 `PindouAI-Android-v2.8.10.apk`。
2. 在系统设置中仅为当前浏览器或文件管理器允许“安装未知应用”。
3. 打开 APK 并完成安装，启动后可离线使用核心制图和完整图纸库。
4. APK 使用项目测试签名，适合体验和验收，不作为应用商店正式签名包。

## Windows 安装

1. 下载 `PindouAI-Windows-v2.8.10-x64-Setup.exe`。
2. 运行安装程序，按向导选择安装位置。
3. 从开始菜单或桌面快捷方式启动 PindouAI。
4. Windows 包内置完整图纸资源；卸载不会影响你另行保存的导出文件。

## 已知边界

- 核心照片转换、画板、作品和导出默认在本机完成，不需要账号或服务端。
- AI 对话、AI 图片、AI 视频、AI 色号识别需要用户自行配置兼容 API，并可能产生第三方费用。
- Android 当前使用测试签名；正式上架前请使用维护者自己的发布 keystore 重新签名。
- 色库中的 RGB/LAB 是工程预置值，实体豆采购应以实际色卡和光线条件复核。
