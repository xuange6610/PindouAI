Offline-first bead design studio

拼豆 AI 设计

把照片、文字和灵感，转换成真正能制作的品牌色号拼豆图纸。

从裁切、降色和色卡匹配，到编号格子、用量统计、手动画板与 PDF 导出，一套 Flutter 应用完成。

Workflow

从一张照片，到一份能开工的图纸

核心流程默认在设备本地完成。用户能在生成前控制尺寸和颜色数量，在生成后检查每格色号与实际用量。

01

导入与裁切

从相册、相机或文件选择主体，校正方向并确定方形构图。

02

设置规格

选择画板尺寸、颜色数量、肤色保护和孤点去噪。

03

生成与核对

通过颜色科学算法映射色卡，查看编号格子和颜色统计。

04

保存与导出

保存到本地作品库，导出 PNG、PDF 与采购数量清单。

Color science

每一个格子，怎样找到对应色号

转换不是普通像素滤镜。输入图像经过裁切、缩放、聚类和感知色差匹配，最终形成可统计、可购买、可打印的色号数据。

INPUT照片方向校正
FRAME正方形裁切
GRID目标格数缩放
CLUSTERLAB 聚类降色
MATCHCIEDE2000 匹配
PALETTE品牌色号映射
OUTPUT图纸与用量清单

Workspace

不止一次转换，而是一套创作工作台

照片制图是主入口，手动画板、文字拼豆、多品牌色卡、作品管理和可选 AI 能力围绕同一份图纸协作。

多品牌色卡

按品牌与系列浏览色号、RGB、HEX 和 LAB 信息，支持检索与导出。

手动画板

使用画笔、橡皮、填充、取色和移动工具，直接编辑每一颗豆。

文字拼豆

把文字渲染为像素稿，为名字、标语和汉字作品提供快速起点。

作品资料库

本地保存、分类、收藏、批量管理、回收站与再次编辑。

换机备份

导出作品、配置、画板和历史记录，在另一台设备恢复。

可选 AI 连接

按需配置兼容 API，用于 AI 制图、对话和多模型工作流。

Run locally

从源码运行

  • Flutter 与 Dart 版本满足 pubspec.yaml
  • Windows 需要 C++ 桌面开发工具链
  • Android 需要 SDK、模拟器或已连接真机
基础照片转换无需服务端。只有 AI 和云同步相关能力需要额外配置。
git clone https://github.com/xuange6610/PindouAI.git
cd PindouAI && flutter pub get
flutter run -d windows
flutter run -d android

代码、真实界面、架构和运行步骤都在同一个仓库。
